개인정보 처리방침

1. 처리하는 개인정보 항목과 수집 방법

구분항목수집 방법
회원 정보이름, 휴대전화번호, 토스 회원 식별키(userKey), 동의한 약관 목록이용자 동의 후 토스 로그인을 통해 토스(주식회사 비바리퍼블리카)로부터 제공받음
분실 신고물건 종류, 물건 이름, 색상, 분실 날짜와 시간, 분실 지역(시/도)과 장소, 특징, 사진(선택)이용자가 서비스 화면에 직접 입력
자동 생성 정보서비스 이용 기록, 접속 IP 주소, 접속 일시서비스 이용 과정에서 자동으로 생성

회사는 주민등록번호 등 고유식별정보와 민감정보를 수집하지 않아요. 분실 신고의 특징 항목에는 이름, 연락처 같은 개인정보를 적지 말아 주세요.

2. 개인정보의 처리 목적

  1. 회원 식별과 로그인 유지, 본인 확인
  2. 분실 신고 등록·관리와 비슷한 습득물 검색 결과 제공
  3. 분실물 찾기 관련 안내, 문의 응대와 고지사항 전달
  4. 부정 이용 방지, 장애 대응과 서비스 안정성 확보

3. 보유·이용 기간

  1. 회원 정보와 분실 신고: 회원 탈퇴(서비스 홈의 "회원 탈퇴") 또는 토스 앱에서 토스 로그인 연결을 끊거나, 토스 로그인 약관 동의를 철회하거나, 토스를 탈퇴할 때까지 보유해요.
  2. 분실 신고와 사진: 이용자가 개별로 지우면 그때 파기해요.
  3. 접속 기록: 수집일로부터 90일 동안 보관해요.
  4. 관련 법령에 따라 보존해야 하는 경우에는 그 기간 동안 보관해요.

4. 파기 절차와 방법

  1. 보유 기간이 끝나거나 처리 목적을 달성한 개인정보는 지체 없이 파기해요.
  2. 전자적 파일 형태의 정보는 복구할 수 없는 방법으로 삭제해요. 회사는 개인정보를 종이 문서로 보관하지 않아요.

5. 제3자 제공

회사는 이용자의 개인정보를 제3자에게 제공하지 않아요. 다만 법령에 특별한 규정이 있거나 수사기관이 법령에 정한 절차에 따라 요청하는 경우에는 예외로 해요.

6. 처리 위탁과 국외 이전

회사는 서비스 운영을 위해 다음과 같이 개인정보 처리를 위탁하고 있으며, 이 위탁에는 개인정보의 국외 이전(보관)이 포함돼요.

수탁자위탁 업무이전 국가이전 항목
Amazon Web Services, Inc.
aws-korea-privacy@amazon.com		 클라우드 서버 운영과 데이터 보관 호주 (AWS 아시아 태평양(시드니) 리전) 1번 항목의 개인정보 전체

이전 시점과 방법: 서비스를 이용하는 시점에 암호화된 네트워크(HTTPS)로 전송해요. 보유 기간: 회원 탈퇴 또는 위탁 계약 종료 시까지. 자세한 내용은 개인정보 국외 이전 동의를 확인해 주세요.

서비스 화면의 광고는 토스(주식회사 비바리퍼블리카)가 제공해요. 회사는 광고를 위해 이용자의 개인정보를 제공하지 않으며, 광고 제공 과정의 정보 처리는 토스의 개인정보 처리방침을 따라요.

7. 이용자의 권리와 행사 방법

  1. 이용자는 언제든지 자신의 개인정보를 열람하거나 정정, 삭제, 처리정지를 요구할 수 있어요.
  2. 분실 신고는 서비스 화면에서 직접 지울 수 있고, 서비스 홈의 "회원 탈퇴"로 회원 정보와 분실 신고, 사진을 한 번에 지울 수 있어요. 탈퇴하면 토스 로그인 연결도 함께 끊어요.
  3. 그 밖의 요청은 privacy@eylabs.co.kr로 보내 주시면 지체 없이 처리할게요.
  4. 법정대리인이나 위임을 받은 사람을 통해서도 권리를 행사할 수 있어요. 이때는 위임장을 제출해야 해요.

8. 안전성 확보 조치

  1. 전송 구간 암호화: 앱과 서버 사이의 모든 통신을 HTTPS로 암호화해요.
  2. 접근 통제: 개인정보를 처리하는 서버와 데이터베이스는 필요한 최소 인원만 접근하고, 접근 권한을 서비스 운영에 필요한 범위로 제한해요.
  3. 본인만 열람: 분실 신고와 사진은 로그인한 본인만 볼 수 있어요.
  4. 데이터베이스 암호화: 회원 정보와 분실 신고를 보관하는 데이터베이스는 저장 시 암호화돼요.

9. 자동 수집 장치

회사는 쿠키를 사용하지 않아요. 로그인 상태를 유지하기 위한 세션 정보는 이용자 기기의 토스 앱 저장소에 보관되며, 이용자가 로그아웃하거나 회원 탈퇴하면 함께 지워져요.
